# Getting help

I maintain these integrations in my free time. Help is **voluntary and best effort**: there is no
guaranteed response time, and supporting the project financially does not create a support
obligation.

## Before you open an issue

1. Read the **README** of the integration, especially *Troubleshooting*.
2. Update to the **latest release** and restart Home Assistant.
3. Search the existing **issues** and **discussions**.

## Where to go

| You want to… | Use |
| :--- | :--- |
| Ask how something works, share a setup | **Discussions → Q&A** |
| Suggest a feature or vote on ideas | **Discussions → Ideas** (give a 👍 to what matters to you) |
| Report a bug | **Issues** (use the bug report form) |
| Report a security problem | **Security → Report a vulnerability** (never a public issue) |

## What to include in a bug report

- Home Assistant version and the integration's version (shown in HACS).
- What you did, what you expected and what happened instead.
- The **diagnostics download** of the integration (*Settings → Devices & services → the
  integration → ⋮ → Download diagnostics*). It redacts credentials.
- The relevant lines from the Home Assistant log, with debug logging enabled for the integration
  (*Enable debug logging* on the integration page). Remove anything personal before posting.

Reports without this information may take longer, because I have to ask for it first.

## Supporting the project

If an integration saves you time, a voluntary tip is appreciated. The links are in each
repository's README.
